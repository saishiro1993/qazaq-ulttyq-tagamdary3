Дәмді Дәстүр — қазақтың ұлттық тағамдары туралы интерактивті сайт.

39 карточек блюд и продуктов с изображениями и описаниями на казахском и русском языках.
В составе: index.html, style.css, script.js, images/, dictionary.json (словарь из Word).
Откройте index.html в браузере. Поиск, категории, избранное, викторина и тренажёр слов используют расширенный каталог.

- Бөлек «Сөздік» бөлімі: қазақша–орысша атаулар, екі тілде іздеу. Сөздік деректері «СӨЗДІК (1).docx» құжатынан алынған.


## Сөйлем құрастыру
Добавлена игра по составлению 13 предложений из документа «Предложения слоаврик.docx»: выбор слов по порядку, отмена выбора, проверка, правильный ответ, счёт и повторное прохождение.

## Обновлённый дизайн
Единая палитра (кремовый, коричневый, зелёный, оранжевый), оформление меню, каталога, словаря, викторины, тренажёров и карточек. Все изображения хранятся локально.


## Фото-викторина
Викторина показывает локальные изображения блюд из папки images вместо текстовых описаний. Нужно выбрать название блюда из четырёх вариантов.
